# Saturday M1 integration release

**Status:** Approved by the owner in chat, 2026-11-19  
**Target:** Working synthetic M1 release by Saturday, 2026-11-21  
**Scope:** Implementation simplification; approved product/safety requirements remain

The owner approved the deadline proposal following M1.6-F. This supplement records
that authorization and supersedes the proposed development sequence of the M1.6-D/F
drafts for this release. It does not mark those drafts Approved or redefine the
seven requirements specifications.

Keep three genuine model-driven roles (Coordinator, Weather, Ocean), all three
activities, natural-language CLI requests, clarification, post-terminal follow-ups,
grounded eligible recommendations, deterministic safety/evidence checks, bounded
investigation/recovery and authoritative local JSONL. Use existing synthetic sources,
catalogs, validators, session manager, result renderer and LangGraph workflow.

Approved deferrals:

- General capability-profile file format/loader and run-wide coverage framework:
  use small explicit configurable tool allowlists with existing contracts.
- Arbitrary overlapping query families and recovery references across delegations:
  freeze legal batches for an investigation and keep recovery within specialist plans.
- Additional wire v0.2 machinery: keep current structured proposals and meaningful
  allowlisted tool identifiers. Never expose fixture outcomes or expected assertions.
- Packaging all acceptance cases through the generic JSON assertion framework:
  retain existing registered scenarios and add focused independent pytest integration
  checks. Report authored, offline-transport and live acceptance scopes accurately.
- Multiple model providers, automatic switching and cumulative dollar-ledger storage:
  keep one explicit model, default-disabled configuration and a manually bounded pilot.
- LangSmith dashboards/experiment management, additional persistence and UI polish:
  keep local traces, existing terminal rendering and process-local sessions.

Do not remove working tests or weaken safety, scope, attribution, time checks,
shared 12-model/12-tool limits, five cycles, one retry per original, one fallback
per required gap, two specialists or three recommendations. Existing M1 exclusions
remain: live environmental providers, real-world numeric hazard thresholds and
verified real-beach catalog completion. This is not full real-world MVP completion.

The owner separately authorized a live-model pilot up to **$1 total and at most ten
investigations**, conditional on locally supplied model access. Calls stay on the
reviewed single profile, with no automatic retries, fixed input/output bounds and
full reservation for uncertain usage. No account upgrade is authorized or needed
by this implementation plan. Revalidate provider pricing before the paid pilot.

Deliver in outcome-based batches: (1) real request-to-result agent/CLI integration,
(2) product acceptance/recovery checks, (3) final installation/regression/demo checks.
Development and routine tests remain offline. Do not commit or push automatically.
